DHOTI UDD - installable app (PWA)

Put this whole folder on any website that uses https, for example:
  - Netlify Drop: open app.netlify.com/drop and drag this folder in. You get a link in a few seconds.
  - GitHub Pages, Vercel, Cloudflare Pages, or a folder on your own domain (like rampyaaryans.me/dhoti).

Then open the link on the phone:
  - Android (Chrome): menu > "Install app" or "Add to Home screen".
  - iPhone (Safari): Share > "Add to Home Screen".
After the first open it works offline.
